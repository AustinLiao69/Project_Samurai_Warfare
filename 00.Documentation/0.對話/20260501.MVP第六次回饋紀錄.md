## 本次回饋清單（共 3 項）

### Item 1：武將評價只有詞彙，不可有 A/B/C ✅
**需求**：家臣一覽的評價徽章只顯示描述詞彙（如「名將之風」、「無敵猛將」），移除 S/A/B/C/D 等級字母。

**實作**：
- `templates/retainers.html` badge 改為 `{{ pair[1] }}`（只取詞彙），移除 `{{ cat[:1] }}{{ pair[0] }}`。
- `grade-X` CSS class 保留，徽章色彩仍由等級決定（S=金、A=綠、B=藍、C=灰、D=暗）。
- hover `title` 屬性仍顯示「類別（等級）」，供玩家對照。
- `.rc-eval-badge` 字體稍調小（0.6rem），padding 加寬（0.4rem）以容納 4 字詞彙。
- `.rr-eval` 改為 `flex-wrap: wrap; justify-content: flex-end;`，確保長詞可換行。

### Item 2：地圖上顯示郡 ✅
**需求**：地圖城節點上除了城資訊外，也要看到對應的郡資訊（郡名、郡類型、代官）。

**實作**：
- `templates/index.html` 城節點 loop 中從 `district_map` 取得對應郡資料：
  - `district_map[castle.id]` → 郡 dict（含 name/type/daikan）
  - 同步查詢 `state.retainers` 找代官名字
- 新增 `.castle-district-bar` 區塊，在兵力下方、點擊提示上方顯示：
  - **郡名**（.cdb-name，金色）
  - **郡類型**（.cdb-type，灰色，如「軍事郡」「商業郡」）
  - **代官名**（.cdb-daikan，藍色，有代官才顯示）
- `style.css` 補充：`.castle-district-bar` / `.cdb-name` / `.cdb-type` / `.cdb-daikan`

### Item 3：家臣一覽升遷指令 ✅
**需求**：家臣一覽中每位武將可接受升遷命令，職級參考 0003.家臣團模組。

**升遷序列**（依 0003 文件）：
```
組頭 → 部將 → 家老 → 宿老
```
大名不在升遷序列內（已是最高職）。

**實作**：
- `app.py` 新增 `RANK_ORDER = ["組頭","部將","家老","宿老"]`。
- 新增 `POST /api/retainer/<id>/promote` API：
  - 驗證武將所屬玩家勢力
  - 依 `RANK_ORDER` 查找目前索引，自動升一級
  - 寫入 log「【升遷】名前：舊階 → 新階」
- `templates/retainers.html`：
  - Jinja2 dict `RANK_NEXT = {'組頭':'部將','部將':'家老','家老':'宿老'}` 計算下一階
  - 每個可升遷武將顯示 `.rr-promote-btn`「▲ 升遷→XXX」
  - JS `promoteRetainer()` 帶確認對話框後呼叫 API，成功後 reload
- `style.css` 補充：`.rr-promote-btn`（綠色框線按鈕，hover 加深背景）
- `.rr-right` 改為 `flex-direction: column; align-items: flex-end`，讓評價 + 升遷按鈕垂直排列
